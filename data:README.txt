DATA STORAGE NOTE
=================

This application does NOT use a server or database.

All student data is stored in the browser's localStorage under the key:
  ihs_science_remediation_v1

This means:
- Data is saved PER DEVICE and PER BROWSER.
- If a student uses a different phone, they will NOT see their old data.
- To transfer data between devices, students must use the "Export Data" feature
  to generate a QR code or copyable code.
- Instructors can import that code into the Instructor Dashboard.

For backup:
- Students can export their data before logging out.
- Instructors can export all imported records to CSV via the Instructor Dashboard
  or the Gradebook.

For privacy:
- Students can delete their data from the device via the "Logout & Delete My Data"
  option in the student app.
- Instructors can clear ALL device data via the "Clear All Device Data" button
  in the Instructor Dashboard.

No personal data is transmitted to any server. The app is fully offline-capable.
